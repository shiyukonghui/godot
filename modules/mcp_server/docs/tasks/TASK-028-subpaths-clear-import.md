## 0. 三项（都是小项，但各有明确判据）

### 1. G-1：**子属性路径**（`position:y`、`v4:x`）当前被 `-32001` 拒绝

**现状**：`editor_set_node_property('position:y')` 与 `('v4:x')` 均 `-32001`；
而引擎有 **`Object::set_indexed` / `get_indexed`**（`core/object/object.h:697-698`，实现 `object.cpp:475-532`）——
**编辑器 Inspector 正是用它**。

**要求**：
1. 让**节点写族 / 读族**支持**子属性路径**（形如 `position:y`、`v4:x`、`material:shader_parameter/uv1_scale` 视引擎支持而定），
   **经同一道闸门**（`value_fits_slot` / 分量表 / §23.4 形状），**不得**新开绕过分支。
2. **语义按引擎**：不存在的子路径 → `-32001` + 建议（消息要**可读**且**指名**哪一段不存在）；
   类型不可 index → `-32602`；写入后**必须读回验证**（§23.4 三层等价）。
3. **读侧**（`editor_get_node_properties` / `running_game_get_node_properties`）是否也支持**按子路径取值**：
   **自己判断**并在报告里给结论（若加，须与契约描述一致；**改描述要报给决策者**）。
4. 证据：`position:y = 3` 真写入（另一个工具读到 `position=(x,3)`）、`v4:x`、`material:shader_parameter/…`（若可用）、
   以及两条**负例**（不存在的子路径 / 不可 index 的类型）。

### 2. G-3：`editor_get_test_report` 的 `clear` **默认 `true`** 且删除**共享**桥接文件

**现状（M4c）**：`clear` 默认 `true`，**一次读取就把别的客户端未读的报告删掉**（多客户端下有破坏性）；
桥接文件是**共享**的（`user://`）。

**要求**：
1. 让**读取不破坏**：默认**不清**（`clear:false`），或把「清」与「读」分成两条清晰语义
   （**任选**，但必须说明理由；**注意这是默认值/语义变化** → 若涉及 `inputSchema` 的 `default`，**报给决策者**由我决定是否走 override）。
2. **多客户端安全**：给出「两个客户端先后读取，先读方**仍能**读到完整报告」的实测。
3. 不可达/为空时维持既有的**诚实空**语义（不得伪造 `total`）。

### 3. D-1：全新工程 + `.tscn` 时**首次 `--import` 必崩**（`0xC0000005`），第二次正常

**现状（TASK-027 实测）**：全新工程目录**且含 `.tscn`** → 首次 `--import` 退出码 `-1073741819`；第二次 `exit 0`；
**不含 `.tscn`** 的工程首次即 `0`。`PLAYBOOK` §3 要求门脚本**校验 `--import` 退出码** —— 也就是说**每个新建骨架工程的门都会碰到它**。

**要求（**界定 + 加固**，不是修引擎）**：
1. **界定触发条件**（最小化实验）：`.tscn` 的存在？**BOM**？`.godot` 缺失？`--import` 与 `--mcp-port=0` 同时给？
   文件内容（`ext_resource` 引用？）？给出**最小复现**与**反向对照**（逐项排除），并在报告里写清**根因判定**；
   若最终**无法**归因到模块，明说「**引擎侧缺陷**」并给出**上游可提交的最小复现材料**（命令、文件、退出码、stderr）。
2. **脚本加固**：`modules/mcp_server/scripts/**` 里所有创建 scratch 工程/跑 `--import` 的地方：
   **不写 BOM**、**校验退出码**、**有界重试**（例如首次失败后重试一次并记录）、
   失败时**输出可诊断信息**（命令、退出码、stderr 摘要、工程路径）。给出加固前后的对照。
3. **写进手册**：把「新工程首次 `--import` 可能崩、脚本必须有界重试 + 校验退出码」补进 `PLAYBOOK` §3
   （**这一条你可以直接改手册**：它属运维纪律，不是规范章节）。
