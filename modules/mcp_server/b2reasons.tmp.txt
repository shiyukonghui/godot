running_game_get_scene_tree (get_game_scene_tree)
经 runtime.rs send_game_command 走 user:// 文件 IPC 到游戏进程取场景树，故 running_game_ 通道。

running_game_get_node_properties (get_game_node_properties)
send_game_command 到运行中游戏读节点属性，故 running_game_。

running_game_execute_gdscript (execute_game_script)
在运行中游戏进程内执行 GDScript，属游戏进程状态写。

running_game_find_nodes_by_script (find_nodes_by_script)
经游戏 IPC 按脚本路径找节点，纯查，故 running_game_ + find_。

running_game_get_autoload_node (get_autoload)
查运行中游戏的 autoload 节点，故 running_game_；与项目磁盘上的 add/remove_autoload 通道明确区分。

running_game_get_node_properties_batch (batch_get_properties)
经游戏 IPC 批量读多节点属性，故 running_game_ + get_，qualifier 用 batch 表明批量。

running_game_find_ui_elements (find_ui_elements)
遍历运行中游戏的 UI 节点，纯查，故 running_game_。
